# Agents start here

This repository is worked on by coding agents of several kinds. Whatever
framework you run in, the instructions are the same:

1. Read [`CLAUDE.md`](CLAUDE.md) completely. Its rules are absolute.
2. Read [the agent working agreement](docs/agents/README.md) and the profile
   for your role.
3. Find the area you are changing in [the area map](docs/areas/README.md) and
   read its guide and the relevant [wiki](docs/wiki/README.md) pages.

Claude Code users can also spawn the role definitions in `.claude/agents/`.
